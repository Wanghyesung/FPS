## 1. 개요

**한 줄 요약:** 플레이어는 좁아지는 자기장 안에서 맵에 떨어진 무기와 아이템을 주워, ML-Agents로 학습된 AI 봇 4마리와 최후의 1인을 가립니다.

- **핵심 판타지:** 3인칭으로 편하게 상황을 파악하다가, 방아쇠에 손을 얹는 순간(조준) 화면이 좁아지며 진짜 사격전이 시작되는 긴장감.
- **세션 길이:** 약 4~6분 (자기장 페이즈 기준, [§6](#6-자기장-시스템) 참고).
- **승리 조건:** AI 봇 4마리를 모두 처치하거나, 최종 자기장에서 유일한 생존자로 남는다.
- **패배 조건:** 플레이어 HP가 0 이하가 된다.

## 2. 범위 (Scope)

### Does (포함)
- 3인칭 기본 시점 ↔ 조준 시 1인칭 시점(견착/스코프) 전환
- 3인칭 미조준 사격 시 탄퍼짐(부정확), 조준 사격 시 정밀 사격
- 맵에 스폰된 무기(AK, TRG) 및 아이템(붕대, 구급상자, 방탄조끼, 탄약) 루팅
- 축소되는 자기장과 자기장 피해
- ML-Agents로 학습된 AI 봇 4마리 (루팅 → 교전 → 저HP 시 도주)
- 미니멀 HUD (체력, 무기/탄약, 자기장 타이머·거리)
- 승리/패배 판정 및 결과 화면

### Does NOT (명시적 제외)
- 네트워크 멀티플레이 (온라인/로컬 모두 제외)
- 차량, 수영, 등반/바인딩(vaulting), 포복(prone)
- 무기 3종 이상, 부착물(스코프 교체, 개머리판 등) 시스템
- 방탄조끼 등급(레벨1/2/3) — 단일 등급만 제공
- 인벤토리 드래그앤드롭 UI, 무게 시스템
- 저장/로드, 메타 진행(스킨, 언락, 시즌 패스)
- 봇 사망 시 무기 드랍 (봇이 들고 있던 무기는 소멸)
- self-play를 통한 봇 간 상호 학습 (플레이어 대역 더미 상대 학습만 수행)

## 3. 핵심 루프 & 매치 흐름

```
매치 시작 → 자기장 대기(1분) → 루팅 & 이동 → 자기장 축소 반복(4단계)
   → 교전(플레이어 vs 봇) → 최종 자기장 → 승패 판정 → 결과 화면
```

플레이어와 봇은 완전히 동일한 서브시스템(WeaponSystem, ZoneSystem, ItemPickupSystem)을 공유합니다 —

## 4. 플레이어 시스템

### 4.1 이동
- 걷기 / 달리기 / 웅크리기 / 점프. 프론(prone), 수영, 등반 없음.
- New Input System 기반 (`.claude/rules/unity-specifics.md` 필수 규칙).

### 4.2 카메라 & 조준 정확도 (핵심 메커니즘)

| 상태 | 카메라 | 조준점 위치 | 탄퍼짐 |
|---|---|---|---|
| 기본(3인칭, 미조준) | 3인칭 숄더캠 | 화면 정중앙 고정 | 무기별 콘(cone) 안에서 무작위 — 정지/이동/점프에 따라 증가 |
| 조준(우클릭 홀드, ADS) | 1인칭 전환 (AK: 견착뷰 / TRG: 스코프 4배줌) | 화면 정중앙 십자선 | 정지 시 0에 수렴, 이동 시에도 대폭 감소 |

- 시점 전환은 0.2초 이내 카메라 블렌드(Cinemachine)로 처리합니다.
- 사격 판정은 **히트스캔(Raycast)** 방식입니다. 3인칭 미조준 시에는 조준점 방향을 중심으로 무기별 콘 각도 안에서 매 발마다 무작위 방향을 재계산해 Raycast를 쏘고, 조준 시에는 카메라 정면 방향으로 그대로 Raycast를 쏩니다.
- 탄퍼짐 구체값은 [§5.1 무기 스탯](#51-무기)에 명시합니다.

### 4.3 무기 소지 & 루팅
- 무기 2슬롯(AK/TRG를 각각 1자루씩, 동시 소지 가능), 1/2 키 또는 마우스 휠로 전환.
- 맵의 무기/아이템 픽업은 근접 시 상호작용 키(E)로 획득. 이미 같은 무기를 들고 있으면 예비탄만 흡수합니다.

### 4.4 HUD (미니멀)
- 체력바, 현재 무기 아이콘 + 탄창/예비탄 숫자, 자기장까지 남은 시간과 거리 표시자, 붕대/구급상자/방탄조끼 보유 개수(슬롯 UI 없이 숫자만).
- 킬/사망 시 짧은 팝업 텍스트.

## 5. 무기 & 아이템

### 5.1 무기

| 항목 | AK (돌격소총) | TRG (볼트액션 저격총) |
|---|---:|---:|
| 사격 방식 | 완전자동, 600RPM | 볼트액션 단발 |
| 몸통 데미지 | 24 | 85 |
| 헤드샷 데미지 | 48 (2배) | 170 (즉사 처리) |
| 탄창 / 예비탄 최대 | 30발 / 90발 | 5발 / 15발 |
| 유효 사거리 | ~80m (초과 시 데미지 감쇠) | 300m+ |
| 미조준(3인칭) 탄퍼짐 | 정지 4° / 이동 8° / 점프 12° | 정지 8° / 이동 20° |
| 조준(ADS) 탄퍼짐 | 정지 0.5° / 이동 3° | 정지 0°(완전 정확) / 이동 5° |
| 재장전/조작 시간 | 2.2초 (탄창 교체) | 1.5초/발 (볼트 조작), 탄창 교체 3초 |

두 무기는 "빠르지만 부정확할 수 있는 자동화기"와 "느리지만 조준하면 확정적인 저격총"으로 대비를 이뤄, 3인칭/1인칭 정확도 전환 메커니즘을 명확히 체감시키는 조합입니다.

### 5.2 아이템

| 아이템 | 효과 | 사용/장착 조건 |
|---|---|---|
| 붕대 (Bandage) | 3초 사용 후 HP +25 (최대 100 초과 불가) | 이동 중 사용 가능 |
| 구급상자 (Medkit) | 6초 사용 후 HP 완전 회복 | 사용 중 이동 불가, 피격 시 사용 취소 |
| 방탄조끼 (Vest) | 총알 데미지 30% 감소 | 장착형(픽업 즉시 교체), 등급 없음, 내구도 없음 |
| AK 탄약 / TRG 탄약 | 픽업 즉시 예비탄에 합산 | 최대치 초과분은 버려짐 (AK 90 / TRG 15 예비탄 상한) |

## 6. 자기장 시스템

작은 도보 맵(반경 200m) 기준 4단계 축소로 설계했습니다. 각 페이즈는 `ZonePhaseDefinition` ScriptableObject 리스트로 데이터화해 기획 조정이 쉽도록 합니다 

| 페이즈 | 경고 시작 | 축소 시간 | 최종 반경 | 초당 피해(자기장 밖) |
|---|---:|---:|---:|---:|
| 0 (대기) | 0:00 | - | 200m (맵 전체) | 0 |
| 1 | 1:00 | 30초 | 130m | 2 |
| 2 | 2:30 | 20초 | 70m | 4 |
| 3 | 3:20 | 15초 | 30m | 6 |
| 4 (최종) | 3:35 | - | 10m | 10 |

- 자기장 밖에 있는 캐릭터는 1초 간격으로 현재 페이즈의 초당 피해량만큼 HP가 감소합니다.
- 최종 페이즈까지 생존자가 2명 이상이면, 유예 시간(60초) 후 강제로 매치를 종료해 스테일메이트를 방지합니다.

## 7. 몬스터 AI (ML-Agents)

### 7.1 정체성
AI 봇은 "몬스터"라는 이름을 쓰지만 실제로는 플레이어와 동일한 규칙(이동/조준/무기/아이템)을 따르는 **인간형 AI 플레이어**입니다. 리깅과 기본 애니메이션을 플레이어와 공유해 제작 비용을 줄입니다.

### 7.2 행동 요구사항
1. 근처 루팅 포인트를 탐색해 무기/아이템을 습득한다.
2. 더 강한 무기(TRG > AK > 무기 없음)를 발견하면 교체를 우선한다.
3. 플레이어가 시야에 들어오고 무기가 있으면 조준·사격한다.
4. 자신의 HP가 30% 미만이면 플레이어로부터 거리를 벌리는 행동을 우선한다.
5. 자기장 밖에 오래 머무르지 않는다.

### 7.3 Behavior Parameters 설계

**관찰(Observation) — 총 158개**
| 그룹 | 구성 | 개수 |
|---|---|---:|
| 자기 상태 | HP 정규화(1), 보유 무기 원핫[없음/AK/TRG](3), 탄약 비율(1), 방탄조끼 착용(1) | 6 |
| 플레이어 인지 | 상대 방향(2) + 정규화 거리(1) + 시야 확보 여부(1) — 시야 밖이면 0벡터 | 4 |
| 자기장 인지 | 중심 상대방향(2) + 경계까지 거리(1) + 자기장 밖 여부(1) | 4 |
| 이동 상태 | 로컬 속도 벡터(2) | 2 |
| RayPerceptionSensor3D | 16방향 레이 × (태그 7종[Player, AK, TRG, Heal, Vest, Obstacle, ZoneBoundary] + 히트여부 + 거리) | 144 |

**행동(Discrete Action) — 4개 브랜치**
| 브랜치 | 값 | 의미 |
|---|---|---|
| 이동 | 5 | 정지/전/후/좌/우 |
| 회전(요) | 3 | 좌회전/유지/우회전 (고정 각속도) |
| 상호작용 | 2 | 없음/줍기·사용 실행 |
| 발사 | 2 | 없음/발사 (무기 미소지 시 시스템에서 무효 처리) |

봇에게는 ADS(조준) 액션을 별도로 두지 않습니다 — 학습 난이도를 낮추기 위해 봇의 사격은 항상 고정된 명중 보정치를 적용하는 것으로 단순화합니다 (§7.5 리스크 완화 참고).

**보상(Reward)**
| 조건 | 값 |
|---|---:|
| 매 스텝 생존 | +0.002 |
| 아이템/무기 픽업 | +0.05 (TRG는 +0.1) |
| 플레이어 명중 1회 | +0.3 |
| 플레이어 처치 (에피소드 종료) | +1.0 |
| 자신 사망 (에피소드 종료) | -1.0 |
| 자기장 밖 체류 (스텝당, 피해와 별개) | -0.01 |
| 저HP(30% 미만)일 때 플레이어와 거리 증가/감소 | +0.01 / -0.01 |

### 7.4 학습 커리큘럼 (3단계)
1. **생존·루팅** — 플레이어 없이 자기장+루팅만 존재. 무기/아이템 습득과 자기장 회피만 학습. (60초 타임아웃)
2. **고정 표적 교전** — 정지된 더미 타겟 추가, 사격·명중 보상 학습.
3. **동적 상대 훈련** — 스크립트 기반 `TrainingDummyPlayerController`(기초 이동 + 고정 명중률 반격)를 상대로 전체 시나리오 학습. self-play는 범위 밖(연산 자원·기간 제약).

`TrainingDummyPlayerController`는 실제 플레이어 컨트롤러가 아닌, 학습 전용 씬에서만 사용하는 별도 컴포넌트입니다 — 실제 구현 대상입니다.

### 7.5 프로젝트 규칙과의 충돌 및 리스크

> ⚠️ **명시적 예외:** `.claude/rules/architecture.md`는 몬스터 AI를 Behavior Tree + SO Action + Blackboard로 구현하는 것을 필수 아키텍처로 규정합니다. 이 프로젝트는 사용자 요청에 따라 **몬스터 AI 전체를 순수 ML-Agents(강화학습)로 구현**하기로 결정했으며, 이는 해당 규칙에 대한 의도적 예외입니다. 향후 다른 몬스터 타입을 추가할 경우에는 원칙대로 BT를 사용합니다 — 이번 예외는 이 프로젝트의 AI 봇에 한정됩니다.

**리스크:** 복합 행동(루팅+교전+도주)을 하나의 정책으로 한 번에 학습시키는 것은 보상 설계 실패 시 이상행동으로 이어질 수 있고, 학습 자체에 코딩 시간과 별개로 긴 wall-clock 시간이 필요해 10일 일정에서 가장 불확실한 구간입니다.

**리스크 완화 — 폴백 계획:**
- `MonsterFallbackController`(단순 FSM: 최근접 루팅 이동 → 시야 내 플레이어 발견 시 고정 명중률 사격 → HP 30% 미만 시 반대 방향 이동)를 별도로 구현해둡니다.
- 학습된 모델(.onnx)이 런타임에 로드 실패하면 **자동으로** 폴백 컨트롤러로 전환합니다(크래시 없이, 경고 로그만 남김).
- 8일차까지 목표 지표(§9 인수 조건 #8 참고) 미달 시, 개발자 판단으로 남은 봇 개체를 폴백 컨트롤러로 전환해 출시 가능한 빌드를 보장합니다.

## 9. 렌더링 & 성능 전략

> `.claude/rules/performance.md`에 따라 렌더링 전략 명시는 선택 사항이 아닙니다.

1. **드로우콜:** 무기 2종 + 아이템 4종으로 고유 메시/머티리얼 수가 적음. 반복 소품(맵 장식물)은 GPU 인스턴싱 활성화.
2. **아틀라싱:** HUD/아이콘(무기 2종, 아이템 4종, 크로스헤어)을 `Assets/Art/Atlases/UIAtlas`로 통합.
3. **머티리얼 공유:** `renderer.material` 접근 금지, 인스턴스별 색상 변경은 `MaterialPropertyBlock` 사용(예: 자기장 경계 pulsing).
4. **배칭:** URP SRP 배처 기본 활성화 확인, 정적 지형/건물은 Batching Static 표시.
5. **UI 캔버스 분리:** `Canvas_HUD`(체력/탄약/자기장 타이머, 매 프레임 갱신) / `Canvas_Popups`(킬피드, 픽업 토스트) / `Canvas_Static`(결과 화면).
6. **오버드로우:** 총구 이펙트·예광탄은 짧은 수명의 풀링된 파티클로 제한, 자기장 경계 셰이더의 반투명 면적 최소화.
7. **카메라/컬링:** 맵 반경 200m 기준 Far Clip ~600m로 충분. 별도 오클루전 컬링은 이번 범위에서 생략(맵 규모가 작아 우선순위 낮음).

## 10. 엣지 케이스

| 케이스 | 기대 동작 |
|---|---|
| 같은 무기를 이미 소지한 상태에서 픽업 | 무기 교체 없이 예비탄만 흡수 |
| 봇이 무기를 든 채 사망 | 무기는 드랍되지 않고 소멸 (범위 밖) |
| 자기장 페이즈 전환 순간 경계에 위치 | 전환 시점의 새 페이즈 피해값을 즉시 적용 |
| 근처에 루팅 아이템이 없음 | RayPerception이 0벡터 반환 → 봇은 이동/탐색 행동으로 자연히 대응 |
| 플레이어와 봇이 같은 프레임에 HP 0 도달 | 플레이어 사망 판정을 우선 처리(봇 생존 여부 무관하게 게임오버) |
| ML-Agents 모델 로드 실패 | 크래시 없이 `MonsterFallbackController`로 자동 전환, 경고 로그 |
| 봇이 지형에 끼여 움직이지 못함 | 에피소드 타임아웃(학습 중) / 런타임에는 일정 시간 무행동 시 강제 리스폰 지점 이동 |
| 구급상자 사용 중 피격 | 사용 취소, 회복 없음 |
| 최종 자기장에서 2명 이상 생존 | 유예 60초 후 강제 매치 종료 |
| 탄창이 빈 무기로 발사 입력 | 발사되지 않음 (부정 테스트 대상) |

## 12. 인수 조건 (Acceptance Criteria)

1. [ ] 3인칭 미조준 상태에서 AK 사격 시, 탄착점은 조준점 기준 정지 시 반경 4° 콘 안에서 무작위로 분산된다.
2. [ ] 우클릭(조준) 입력 시 0.2초 이내 카메라가 1인칭 시점(AK 견착뷰 / TRG 스코프뷰)으로 전환된다.
3. [ ] TRG를 조준하고 정지한 상태에서 발사하면 탄착점은 화면 정중앙 십자선과 정확히 일치한다(분산 0).
4. [ ] 자기장 밖에 있는 캐릭터는 현재 페이즈의 초당 피해량만큼 1초 간격으로 HP가 감소한다.
5. [ ] 자기장 안에 있는 캐릭터는 자기장 피해를 전혀 받지 않는다. (부정 테스트)
6. [ ] 붕대 사용 시 3초 후 HP가 25 회복되며 100을 초과하지 않는다.
7. [ ] 방탄조끼 착용 중에는 총알 피해가 30% 감소해 적용된다.
8. [ ] 학습된 봇 정책은 HP 30% 미만 평가 에피소드 100회 중 70% 이상에서 플레이어와의 거리를 증가시키는 행동을 보인다.
9. [ ] 학습된 몬스터 정책(.onnx) 로드에 실패하면 크래시 없이 `MonsterFallbackController`로 자동 전환된다.
10. [ ] 봇 4마리 + 총알/이펙트가 동시에 발생하는 교전 상황에서도 60FPS 이상을 유지한다. (성능 조건)
11. [ ] 플레이어 HP가 0 이하가 되면 같은 프레임 내 봇 생존 여부와 무관하게 즉시 게임오버 화면이 표시된다.
12. [ ] 탄창이 빈 무기는 발사 입력을 받아도 발사되지 않는다. (부정 테스트)
13. [ ] 최종 자기장(페이즈4) 진입 후 60초가 지나면 생존자 수와 무관하게 매치가 강제 종료된다.

## 14. 개발자 액션 필요 (에이전트가 대신 할 수 없는 수동 작업)

1. **패키지 설치** — `Packages/manifest.json`에 `com.unity.inputsystem`, `com.unity.cinemachine`, `com.unity.ml-agents` 추가 후 Package Manager에서 해석 확인. Python 학습 환경은 `pip install mlagents`로 별도 설치.
2. **캐릭터 에셋** — 플레이어/봇 공용 휴머노이드 리그와 기본 애니메이션(이동/조준/발사/피격/사망)을 소싱(예: Mixamo) 또는 제작. 에이전트는 3D 모델/애니메이션을 직접 만들 수 없습니다.
3. **무기 모델** — AK, TRG 모델 및 총구 부착 포인트(muzzle socket) 준비.
4. **환경 아트** — 400m 규모 맵의 지형/건물 그레이박스 이후 비주얼 패스(에셋 팩 소싱 또는 직접 제작).
5. **UI 스프라이트 아틀라스** — Project 창 우클릭 → Create → 2D → Sprite Atlas → `UIAtlas`로 이름 지정 → HUD/아이콘 스프라이트 포함 → Tight Packing/Allow Rotation 활성화.
6. **Behavior Parameters 컴포넌트 값 확정** — §7.3에서 설계한 관찰(158)/행동(4브랜치) 수치를 `MonsterAgent`의 Behavior Parameters 인스펙터에 반영하고, 학습용 씬에서 Academy 설정 확인.
7. **GPU 인스턴싱/정적 배칭 플래그** — 반복 소품과 정적 지형에 인스펙터에서 직접 표시.

이 항목들이 준비되기 전까지, 이를 참조하는 코드(아틀라스 경로, 캐릭터 애니메이터 파라미터 등)는 구현하지 않습니다.
