## 지금 몬스터(Enemy) 행동

### 1순위 — Chase(추격)

아래 두 조건을 둘 다 통과해야 진입

- 플레이어가 **40 범위 이내** 
- 플레이어가 몬스터 정면 기준 **시야각 80도 이내** (`SO_CheckPOVNode_80`)

둘 다 만족하면 `TraceMoveNode`가 매 프레임 NavMeshAgent 목적지를 플레이어 위치로 계속 갱신 (아직 구현 X)

### 2순위 — Patrol(순찰)

위 조건이 하나라도 안 맞으면 이쪽으로 빠짐

- `CheckPoint0 → 1 → 2 → 3 -> 4`을 순서대로 돌면서 이동 
- 도착지 근처(1 유닛 이내)에 도달하면 다음 체크포인트로 인덱스 넘어가고 반복 

### 아직 없는 것

- 공격/사격 로직 자체가 트리에 없음 — 그냥 순찰만 함
- `Enemy.TakeDamage`도 빈 함수라 총 맞아도 아무 반응 없음

### 오류

-적이 나를 추격하지 않음
